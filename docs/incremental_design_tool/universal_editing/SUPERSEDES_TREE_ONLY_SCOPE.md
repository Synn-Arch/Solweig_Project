# Scope precedence

This universal editing specification supersedes any statement that defines the product solely as a tree-placement or tree-editing tool.

The existing tree prototype remains valid as:

- the first `vegetation_geometry` adapter;
- a frontend interaction reference;
- a local-invalidation test case;
- a benchmark and scientific-differential fixture.

It is not the complete editor registry. Subsequent code should avoid adding new component-specific branches directly to the central worker or frontend state machine. Add an adapter, source node, dependency mapping, validation fixtures, and capability metadata instead.
