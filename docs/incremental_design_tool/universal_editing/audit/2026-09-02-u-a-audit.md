- **A1 vegetation_geometry**: `raster_patch` is not implemented (only object
  rasterization: trees.py:96-160 `rasterize_tree_patch`, discs, max-combine).

- **A4 landcover_surface**: input optional (solweig_gpu.py:437-446;

  (solweig.py:130, :2195) → dead branch after cleaning; painting water never
  receives Twater treatment.
- **A5 meteorological_forcing**: the worker hard-fails if the met text differs
  from the cached f32 (solver.py:286-290) and cross-checks recomputed solar
  against the cache (:314-323) → met edits currently REQUIRE a scenario-forcing
  overlay + scoped cross-check relaxation; `selected_date_str` is validated
  against met row 0 (:324-332).
- **A6 selected_date_time**: `native_input` overstates reality — no runtime
  scalar exists; it is met cols 0-3 + the solar series + `altmax` (which also

- **A9 output_view**: local solve supports `kup/kdown/lup/ldown/ta/wind` via
